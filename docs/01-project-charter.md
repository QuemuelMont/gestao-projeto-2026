# Project Charter — SIGER

## 1. Identificação do Projeto

**Nome:** Sistema Inteligente de Gestão Energética Residencial (SIGER)

**Área:** Engenharia Elétrica / Automação / Internet das Coisas (IoT)

**Tipo:** Projeto de desenvolvimento tecnológico

**Duração estimada:** 8 semanas

## 3. Justificativa

O consumo de energia elétrica residencial representa uma parcela significativa dos gastos mensais das famílias. Entretanto, muitos consumidores não possuem informações detalhadas sobre quais equipamentos consomem mais energia, em quais horários ocorre maior consumo e onde existem possíveis desperdícios.

Dessa forma, o projeto propõe o desenvolvimento de um sistema inteligente capaz de monitorar o consumo elétrico e utilizar Inteligência Artificial para analisar os dados e fornecer informações e recomendações ao usuário.

## 4. Problema

Como monitorar e analisar o consumo de energia elétrica de uma residência de forma acessível e inteligente, permitindo identificar desperdícios e auxiliar o usuário na redução do consumo?

## 5. Objetivo Geral

Desenvolver um protótipo de um sistema inteligente capaz de monitorar o consumo de energia elétrica residencial, analisar os dados por meio de Inteligência Artificial e fornecer informações e recomendações para melhorar a eficiência energética.

## 6. Objetivos Específicos

- Medir o consumo de energia elétrica através de sensores;
- Utilizar um ESP32 para aquisição e processamento dos dados;
- Transmitir os dados por meio de Wi-Fi;
- Armazenar o histórico de consumo;
- Desenvolver uma interface para visualização das informações;
- Identificar padrões de consumo;
- Detectar possíveis situações de desperdício;
- Utilizar IA para analisar os dados coletados;
- Estimar o consumo energético;
- Fornecer recomendações para economia de energia;
- Validar o funcionamento do protótipo através de testes.

## 7. Escopo

## 10. Principais Riscos

| Risco | Impacto | Ação preventiva |
|---|---|---|
| Erros nas medições | Alto | Calibração dos sensores |
| Falha de componentes | Médio | Testes individuais e componentes reserva |
| Problemas de Wi-Fi | Médio | Armazenamento local temporário |
| Dados insuficientes | Alto | Realizar coleta durante período adequado |
| IA apresentar resultados inadequados | Alto | Validar resultados com dados reais |
| Atrasos no desenvolvimento | Alto | Dividir tarefas entre integrantes |
| Problemas na montagem elétrica | Alto | Utilizar procedimentos de segurança e testes controlados |
