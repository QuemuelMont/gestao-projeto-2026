# Sistema Inteligente de Gestão Energética Residencial (SIGER)

## Sobre o projeto

O SIGER é um projeto de desenvolvimento tecnológico voltado ao monitoramento e à otimização do consumo de energia elétrica residencial.

O sistema busca fornecer informações sobre o consumo em tempo real e utilizar Inteligência Artificial para identificar padrões de consumo, detectar possíveis desperdícios e gerar recomendações para economia de energia.

## Objetivo

Desenvolver um protótipo funcional capaz de monitorar o consumo de energia elétrica de uma residência, apresentar os dados ao usuário por meio de uma interface/dashboard e utilizar Inteligência Artificial para análise dos dados.

## Tecnologias

- ESP32
- Sensores de corrente e tensão
- Sensores ambientais e de presença, quando necessários
- Wi-Fi / IoT
- Banco de dados
- Dashboard / interface
- Inteligência Artificial
- Relés ou módulos de acionamento, caso sejam utilizados
